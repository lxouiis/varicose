# Cevi Project (varicose)

This repository contains the full stack for the Cevi project, a comprehensive medical registry and clinical assessment platform designed for tracking and managing Chronic Venous Insufficiency (CVI) and varicose veins.

The system facilitates patient registration, clinical assessments (including CEAP classification and rVCSS scoring), and the management of both clinical and ultrasound (Doppler) imaging data.

## Structure
- `backend/`: The backend server (Node.js, Express, Prisma, MySQL). Handles patient data, assessments, image uploads, and AI data models.
- `frontend/`: The frontend web application (React, Vite, Tailwind CSS). Provides the user interface for doctors and medical staff to manage the CVI registry.
- `notebooks/`: Jupyter notebooks used for data analysis and machine learning experiments.
- `assets/`: Various assets, images, and models.
- `docs/`: System documentation and handover guides.
- `scripts/`: Utility and database seeding scripts.
